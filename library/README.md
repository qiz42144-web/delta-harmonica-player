# 本地曲库说明

## 添加自己的曲库

曲库可以放在电脑的任意目录，不必放进项目：

1. 启动 `三角洲口琴自动演奏器.exe`；
2. 打开左侧「曲库」标签页；
3. 点击「选择曲库文件夹…」；
4. 选择存放 MIDI 的文件夹；
5. 双击歌曲载入，程序会自动切到「轨道」页并推荐主旋律轨。

程序会递归扫描以下格式：

- `.mid`
- `.midi`
- `.kar`
- `.rmi`

选择会保存在本地 `config.json`，下次启动仍然有效；该配置文件不会提交到 GitHub。

## 推荐使用流程

1. 载入 MIDI；
2. 选带 `★` 的推荐轨道，或手动试听其他轨道；
3. 点击「试听本段」，确认旋律；
4. 根据需要设置段落、速度、移调和单音合并方式；
5. 按 `F6` 开始，倒计时期间切回游戏；
6. 按 `F8` 随时停止。

## 轨道数字含义

例如：

```text
★ [1] Piano  1311→1283  吃音28  折叠22  移调-12
```

- `1311→1283`：原始 1311 个音，转换后可吹 1283 个；
- `吃音28`：28 个重叠音在单声部化时被移除；
- `折叠22`：22 个超出游戏音域的音被按八度折回；
- `移调-12`：整轨降低一个八度后更适合游戏口琴。

第 0 轨常用于曲名、速度和版权信息，显示「空轨」是正常的，不需要选择。
