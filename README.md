# 三角洲口琴自动演奏器

> 当前版本：**v0.4.6** · [下载最新版 exe](https://github.com/qiz42144-web/delta-harmonica-player/releases/latest)

导入 MIDI → 选一条轨道 → **先在电脑上试听** → 点开始（或按 `F6`）→ 切回游戏，倒计时结束后自动吹口琴。

核心播放器纯 Python 标准库实现（**零第三方运行依赖**，只有打包时用 PyInstaller），
用 `build.bat` 一键打包成**单文件 exe**。

v0.4.6 已支持：曲库、轨道分析、本地试听、段落选择、变速建议、自动移调、
「取最高音 / 后起优先」单音合并、「只在开头 / 所有空档」钢琴填补，以及自动跳过开头静音。

## 一、最快上手

### 方式 A：直接用 exe（推荐给只想用的）

1. 双击 `build.bat`（或在 `dist\` 里拿现成的），产物是 `dist\三角洲口琴自动演奏器.exe`；
2. 双击 exe，**同意 UAC 管理员权限提示**（不授权的话，游戏收不到模拟按键）；
3. 在左边「**曲库**」标签页点「选择曲库文件夹…」，指向你放 MIDI 的目录，
   之后**双击曲目**即可载入（文件夹会记住，下次打开还在）；
4. 自动切到「**轨道**」标签页，程序已按「真吹得出来多少音」帮你选好主旋律轨，想换就点另一条；
5. **点「试听本段」先听一遍**（只出声、不发送按键），确认旋律和调性没问题；
6. 点「▶ 开始演奏 (F6)」，倒计时里切回游戏、拿出口琴，等它自己开始吹；
7. 想停就按 `F8`（全屏游戏里也有效）。

> 界面里所有反馈都在**底部日志框**：解析结果、指法预览、错误提示都写在那里。
> 不知道「轨道」「吃音」「折叠」是什么意思，点右上角「**使用说明 / 名词解释**」。
>
> 添加本地 MIDI 的完整步骤见 [`library/README.md`](library/README.md)。

### 方式 B：直接跑源码

```bat
python main.py
```

## 二、试听 / 段落 / 变速建议（v0.4.0 新增）

**试听本段** —— 把当前轨道（或当前段落）合成成 WAV 直接在电脑上播，
**完全不发送键盘鼠标事件**，所以可以放心在游戏外先听：
听到的就是待会儿游戏里会吹出来的东西（同一份时间线，同样的跳音与截断）。

**段落** —— 一首 4 分钟的曲子不必整首吹。底部「段落」一行可以设起止秒数，
或用「前 30 秒 / 后 30 秒」快速定位，`试听本段` 和 `开始演奏` 都只处理这一段。
跨过边界的音会被截断，不会整段丢。

**变速建议** —— 如果这首曲子有大量「时值太短、游戏根本收不到」的音，
按钮上会直接显示建议值（例如 `建议 0.75x`），点一下就应用。
它按「救回一半过短音」来算，不会为了几个音把整首拖成慢动作。

## 三、键位与原理

游戏内口琴（守夜人的口风琴）的键位模型：

```
键盘    Z  X  C  V  B  N  M  ,
音级    1  2  3  4  5  6  7  1̇        → 半音偏移 0 2 4 5 7 9 11 12

鼠标左键按住 = 整排 −12 半音（降八度）
鼠标右键按住 = 整排 +12 半音（升八度）
鼠标中键按住 = 整排 +1  半音（升半音）
左/右键互斥，中键可与二者叠加

pitch = P0 + 12×shift + degree[key] + sharp      shift ∈ {−1,0,+1}, sharp ∈ {0,1}
```

三个八度带（−12..+1 / 0..+13 / +12..+25）拼起来覆盖 `P0−12 … P0+25` 共 **38 个半音**，
中间有重叠、没有空洞 —— 所以这件乐器是**完全半音阶**的，任何调都能吹。

程序做的事：

1. 解析 MIDI（含 tempo map、running status、通道 10 打击乐识别）；
2. 把每个音解成 `(八度修饰键, 琴键, 半音修饰键)` 的候选集合；
3. 用**动态规划**在整首曲子上挑一条「鼠标修饰键切换最少、手指跨键最少」的指法；
4. 编译成带绝对毫秒时间戳的事件流（单音收敛 + 最短音长 + 音符间隔）；
5. `SendInput` 按 1ms 精度回放。

## 四、参数怎么调

| 参数 | 默认 | 说明 |
|---|---|---|
| 速度 | 1.00 | 0.5 = 半速（慢曲更好听），1.5 = 一点五倍速 |
| 移调 | 0 | 整体升降调（半音），键位不动 |
| 倒计时 | 4 秒 | 留给你切回游戏的时间 |
| 音符间隔 | 12 ms | 相邻音之间留的空隙，糊在一起就调大 |
| 最短按住 | 35 ms | 太短的音游戏会吞掉，适当调大更稳 |
| 基准音 P0 | 60 | 游戏内中音「1」对应的 MIDI 音高，一般不用改 |
| 自动选最佳移调 | 开 | 在 −6…+6 半音里挑一个，让调外音（要按中键的音）最少 |
| 自动整体适配八度 | 开 | 整首歌偏高/偏低时整体移八度；只有零星越界音时不触发 |
| 超范围音按八度折叠 | 开 | 关掉则直接丢弃越界音 |
| 干跑测试 | 关 | 只写日志、不发送按键，用来先看指法对不对 |

轨道列表里每条轨道都会显示「**可吹 N 音 / 吃音 / 折叠 / 整轨移调**」，这是按真正
能吹出来的音符数算的，不是原始音符数 —— 选轨道时看这个数字。

```bat

三角洲口琴自动演奏器.exe --play "demo\小星星.mid" --track 2 --speed 0.8 --auto-transpose --countdown 5
```

窗口版 exe 也能从命令行调用：它会自动附着到调用方的控制台输出结果。

## 六、曲谱体检工具

拿到一批 MIDI 不知道哪个能吹、该选哪条轨时，直接批量体检：

```bat
python tools\analyze_midis.py "D:\某个文件夹"
```

输出每条轨道的音符数 / 音域 / 中位时值 / 和弦密度，以及「可吹多少音、吃音多少、
要不要整轨移调、自动移调建议多少、八度切换多少次」，并指出具体问题。

`tools\melody_sweep.py` 是当初用来决定「要不要上复杂旋律提取算法」的参数扫描脚本，
结论是收益不足（最多 +1.2 个百分点），所以最终只保留了最简单的取最高音。

## 七、把歌曲变成 MIDI（两条路）

### 7.1 有简谱：直接转换（音高 100% 准确，推荐）

```bat
python tools\score_to_midi.py "简谱.txt" -o "曲子.mid" --preview "试听.wav"
```

识别的记法：数字 1-7 为音级、`( )` 低八度、`[ ]` 高八度、`*` 表示原谱此处是升号、
`|` 为换气、`→` 后面是歌词。**节奏**：简谱没给时值，脚本按「一字一音」给规整节奏
（默认 90 BPM 八分音符，句尾四分、换气处八分休止、段落间两拍），可用 `--bpm` 调。
`--simplified` 忽略 `*` 号，全用自然音。

### 7.2 只有音频：人声转录（需要 numpy + ffmpeg）

```bat
python tools\vocal_to_midi.py "歌曲.mp3" -o "人声旋律.mid" --preview "试听.wav"
```

流程：ffmpeg 解码 → 150Hz 高通（压掉贝斯/底鼓）→ YIN 基频跟踪 →
能量/置信度门控 → 中值滤波 + 八度纠错 → 按片段取中位数切成音符 →
按精确毫秒写 MIDI（默认不量化，保留演唱的自由节奏；`--quantize 16` 可对齐网格）。

参数：`--fmin/--fmax` 音域、`--min-note-ms` 最短音、`--highpass` 高通截止。

**限制**：没有做人声分离，伴奏会干扰音高检测——鼓点密集或乐器旋律强的段落容易出错。
要求更高就应该先用 Demucs / Spleeter 之类分出人声轨，再喂给这个脚本。

### 7.3 钢琴录音：多音转录 + 口琴单声部版

钢琴应使用专门的多音模型，而不是 YIN：

```bat
:: 建议先指定缓存、临时目录和模型目录到非系统盘
set PIP_CACHE_DIR=E:\piano-tools\pip-cache
set TMP=E:\piano-tools\tmp
set TEMP=E:\piano-tools\tmp
set PIANO_MODEL_DIR=E:\piano-tools\model

:: CPU 版 PyTorch + 钢琴转录依赖
python -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
python -m pip install piano_transcription_inference audioread

python tools\piano_to_midi.py "钢琴.flac" ^
  -o "完整多音.mid" --mono-out "口琴单声部.mid" --preview "试听.wav" ^
  --model-dir "%PIANO_MODEL_DIR%"
```

首次运行会把约 164MB 的模型下载到 `--model-dir`；脚本使用 `urllib`，不依赖 Windows 没有的
`wget`。完整 MIDI 保留左右手全部声部；单声部版会先限制旋律音域，再用连续性动态规划选线。
这是启发式降声部，复杂琶音开头仍可能被当成旋律，试听后可用 `--melody-lo / --melody-hi` 调整。

## 八、文件结构

```
delta-harmonica-player/
├─ main.py       GUI 主程序 + 命令行入口
├─ smf.py        MIDI(SMF) 解析器：tempo map / 轨道 / 音符配对
├─ mapping.py    音高 → 键位求解 + 自动选轨 + 自动移调 + DP 指法 + 段落 / 变速建议
├─ synth.py      本地试听：波表合成 WAV + winsound 异步播放（不发按键）
├─ player.py     SendInput 注入 / 1ms 定时 / 卡键兜底 / F6-F8 热键
├─ demo_midi.py  生成测试用 MIDI（小星星 + 打击乐轨 + 伴奏轨）
├─ selftest.py   无 GUI 自检（106 项：解析 / 映射 / 合并 / 填补 / 试听 / 定时 / 幂等）
├─ tools\gui_smoke.py       GUI 冒烟测试（曲库→轨道→段落→试听→填补→演奏→关窗，20 步）
├─ tools\analyze_midis.py   批量曲谱体检
├─ tools\inspect_midi.py    查看 MIDI 音符、音域和时间密度
├─ tools\score_to_midi.py   数字简谱 txt → MIDI
├─ tools\vocal_to_midi.py   单人声/弱伴奏音频 → 单声部 MIDI（需要 numpy + ffmpeg）
├─ tools\tempo_probe.py     测量 BPM 和吐字速率（需要 numpy）
├─ tools\pyin_transcribe.py pYIN 声乐音高跟踪（需要 librosa）
├─ tools\piano_to_midi.py   钢琴录音 → 多音 MIDI + 单声部版（需要 torch 模型）
└─ build.bat     一键打包单文件 exe
```

## 九、常见问题

**界面上的「轨道」「吃音」「折叠」是什么意思？**
点程序里的「**使用说明 / 名词解释**」按钮，有完整解释。简单说：
一个 MIDI 文件里可以有好几条轨道（不同乐器/声部），口琴一次只能吹一条；
`197→196` 表示原始 197 个音、真正能吹出来 196 个；`吃音` 是被重叠音吃掉的、
`折叠` 是超出音域被挪到最近八度的；第 0 轨常常只有曲名信息，显示「空轨」是正常的。

**为什么看不到输出 / 点了「预览指法」像没反应？**
所有输出都在窗口**最下方的日志框**（0.3.0 起固定在底部，不会再被挤出去）。
状态栏也会同步给出一句话反馈。

**点了「试听本段」没声音 / 报了 `Cannot play asynchronously from memory`？**
v0.4.1 已修：Windows 的 `winsound` 不支持「内存 + 异步」播放，所以现在会先落一个临时
WAV 到 `%TEMP%`（`dsh-harmonica-preview-*.wav`），播完/停止时自动删除。
如果还是没声音，先确认系统没静音、默认播放设备正常。
长曲子为了不卡，最多合成 60 秒，想听后面的就用「段落」选一段再试听。

**每次启动都弹 UAC？**
这是故意的：exe 里嵌了 `requireAdministrator` 清单。游戏若以管理员身份运行，普通权限程序发的模拟输入会被系统直接丢弃（UIPI）。
只想自己先试试、不想每次点 UAC 的话，编辑 `build.bat`，把 `set "UAC_FLAG=--uac-admin"` 里的 `--uac-admin` 删掉重新打包即可。

**exe 会不会带一个黑色控制台窗口？**
不会。打包参数里有 `--noconsole`，PE 子系统是 GUI（可用 `--check` 或看 exe 属性确认）。

**按了开始但游戏里没反应？**
1. 十有八九是权限：右键 exe →「以管理员身份运行」。游戏若以管理员启动，普通权限的模拟输入会被系统直接丢掉（UIPI）。
2. 用「干跑测试」配合 `--check` 确认程序本身在发事件。
3. 游戏用了 DirectInput / Raw Input，本程序已用**扫描码**发送键盘事件；如果你改过游戏的键位，需要在 `mapping.py` / `player.py` 的 `DEFAULT_SCANCODES` 里同步改。

**杀毒软件报毒 / SmartScreen 拦截？**
PyInstaller 打包的未签名 exe 常见误报，加信任即可；也可以直接跑源码 `python main.py` 绕开。

**节奏漂、抢拍？**
把「音符间隔」调大一点（15–20ms），或把速度降到 0.9；程序内部已用 `timeBeginPeriod(1)` + 自旋把定时误差压到 1ms 内。

**会不会卡键？**
不会。任何停止/异常/关窗/进程退出都会无条件松开所有按键与鼠标三键（`release_all` + `atexit`），演奏期间也不动鼠标坐标，不会转视角。

**ATK 鼠标能用吗？**
能。本程序**不经过任何鼠标驱动**，直接在 Windows 层发键鼠事件，所以鼠标什么牌子都无所谓。
（反过来，如果你想让演奏走 ATK HUB 的宏，目前没有开源转换器，只能用 Harmonica Deck 的录制助手录进 ATK HUB。）
